# Homepage maintenance

Read README.md for the content map and deployment procedure. This is a small Jekyll site derived from al-folio; unused theme components have been removed.

- Preserve confirmed academic facts, submission statuses, the original portrait and all three paper figures.
- Keep the five pages on the shared academic layouts and content data.
- Before publishing, run the production Jekyll build and Prettier check; check links, desktop/mobile rendering and entrance interaction.
- Work on a development branch. Do not force-push. Publish only within the user's authorization.
- Keep screenshots, logs and reference materials outside the repository.
- `main` contains source; `gh-pages` contains the live generated site. Both are required. Do not delete `gh-pages` when cleaning development branches.
